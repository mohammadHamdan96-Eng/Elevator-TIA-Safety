# Elevator demonstration video

Use this exact repository filename:

```text
Elevator_Automatic_Safety_Demo.mp4
```

Final repository path:

```text
media/video/Elevator_Automatic_Safety_Demo.mp4
```

Recommended video flow:

1. healthy/acknowledged safety state;
2. WinCC overview;
3. valid floor request;
4. automatic travel;
5. arrival / final motion removed;
6. short diagnostics or safety view;
7. clean final state.

## Inline playback in the README

After uploading the repository, edit `README.md` on github.com and drag the MP4 directly below the `GITHUB INLINE VIDEO` comment near the top of the README. GitHub will insert a `user-attachments` URL that renders as an inline player.

Keep the original MP4 in this folder as the organized repository copy. The GitHub-generated attachment is only for convenient inline playback.

H.264 MP4 is recommended for broad browser compatibility.
